# ivy-gltf
GLTF asset loading and management.

## Key Components
### Document
Parsed GLTF with buffers, images, meshes, skins.

### GltfNode, GltfMesh, GltfMaterial, GltfPrimitive
Accessors for GLTF elements.

### GltfNodeDesc
Descriptor for loading nodes.

### Animation
Skin, animation data.

## Modules
- `animation`: Animation handling (skin)
- `components`: GLTF components
