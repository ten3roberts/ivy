# Editor and Tools
Ivy includes an integrated editor for rapid development and content creation.

## Property Editing
Modify component values in real-time through an intuitive UI.

## Gizmos
Visual debugging tools for transforms, colliders, and custom data.

## Template Editing
Create and edit entity templates visually without code.

## Scene Management
Load, edit, and save scenes with the `.ivsc` format.

## Hot Reloading
Changes to assets and code reload automatically.

## Inspector
Examine and modify entity hierarchies and components.

## Viewport
3D viewport with camera controls and multiple view modes.

## Asset Browser
Browse and manage project assets.

## Play Mode
Test gameplay within the editor environment.

## Prefabs
Reusable entity templates with override capabilities.
